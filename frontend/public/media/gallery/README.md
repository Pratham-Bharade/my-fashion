# ✨ Design Gallery Media Folder (`/public/media/gallery/`)

Use this folder to update design videos and photos for the **Design Gallery & Portfolio**.

### 📁 Category Video Files:
- **`bridal-couture.mp4`**: Bridal silk sarees, heavy lehenga choli video.
- **`designer-blouse.mp4`**: Back neck patterns, maggam work blouse video.
- **`lehenga-choli.mp4`**: Festive & wedding lehengas video.
- **`festive-kurti.mp4`**: Daily wear, cotton & festive kurti styles.
- **`party-gown.mp4`**: Anarkali suits & Western evening gowns.
- **`embroidery-work.mp4`**: Handcrafted zardozi, aari, and thread embroidery.

### 💡 How Admin Can Update:
1. To change the trending video for any category, replace the corresponding `.mp4` file here.
2. You can also upload custom design photos/videos directly from the **Admin Panel ➔ Gallery Designs (`/admin/designs`)**!
