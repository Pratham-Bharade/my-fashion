# 🏠 Homepage Media Folder (`/public/media/home/`)

Use this folder to update photos, banners, and videos on the **Homepage**.

### 📁 Files in this folder:
- **`hero-photo.png`**: The main banner photo shown in the hero section on the homepage.
- **`hero-video.mp4`** *(optional)*: If you want to use a trending video background or hero clip instead of a photo.
- **`story-photo.png`**: Atelier / boutique craftsmanship story image.

### 💡 How Admin Can Update:
1. Replace `hero-photo.png` with any new trending fashion saree/blouse photo.
2. Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.mp4`.
